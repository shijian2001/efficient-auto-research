# ML-Master 2.0 — MLE-Bench Lite

The launcher is implemented, but this is not evidence of a formal score. The
shared schema-v2 manifest, model track, clean source and real scored smoke must
be ready before this cell enters the seven-Agent comparison.

Use `BenchmarkAdapters.MLEBenchLite.adapter.MleLiteAdapter` with `--agent ml-master-2`
and a generated per-run config. The config must pin public data, GPU, timeout,
embedding settings, and the shared relay; the upstream example is not copied
because it contains task-specific paths.
